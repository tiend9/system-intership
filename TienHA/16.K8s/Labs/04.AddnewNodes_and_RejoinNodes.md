## 6. Tạo Playbook `prepare-nodes.yml`

Tạo file:

``` bash
nano prepare-nodes.yml
```

Nội dung:

``` yaml
---
- name: Chuẩn bị toàn bộ node cho Kubernetes cluster
  hosts: k8s
  become: yes

  tasks:

    - name: Set hostname
      ansible.builtin.hostname:
        name: "{{ inventory_hostname }}"

    - name: Cập nhật /etc/hosts
      ansible.builtin.blockinfile:
        path: /etc/hosts
        marker: "# {mark} ANSIBLE KUBERNETES HOSTS"
        block: |
          192.168.70.148 controlplane
          192.168.70.149 workernode1
          192.168.70.150 workernode2

    - name: Tắt swap ngay lập tức
      ansible.builtin.command: swapoff -a
      when: ansible_swaptotal_mb > 0

    - name: Comment swap trong fstab
      ansible.builtin.replace:
        path: /etc/fstab
        regexp: '^([^#].*\sswap\s.*)$'
        replace: '# \1'

    - name: Load kernel modules
      ansible.builtin.copy:
        dest: /etc/modules-load.d/k8s.conf
        mode: '0644'
        content: |
          overlay
          br_netfilter

    - name: Modprobe overlay
      community.general.modprobe:
        name: overlay
        state: present

    - name: Modprobe br_netfilter
      community.general.modprobe:
        name: br_netfilter
        state: present

    - name: Cấu hình sysctl cho Kubernetes
      ansible.builtin.copy:
        dest: /etc/sysctl.d/k8s.conf
        mode: '0644'
        content: |
          net.bridge.bridge-nf-call-iptables = 1
          net.bridge.bridge-nf-call-ip6tables = 1
          net.ipv4.ip_forward = 1

    - name: Áp dụng sysctl
      ansible.builtin.command: sysctl --system

    - name: Cài containerd
      ansible.builtin.apt:
        name: containerd
        state: present
        update_cache: yes

    - name: Tạo thư mục config containerd
      ansible.builtin.file:
        path: /etc/containerd
        state: directory
        mode: '0755'

    - name: Generate default config containerd
      ansible.builtin.shell:
        cmd: containerd config default > /etc/containerd/config.toml
        creates: /etc/containerd/config.toml

    - name: Bật SystemdCgroup
      ansible.builtin.replace:
        path: /etc/containerd/config.toml
        regexp: 'SystemdCgroup = false'
        replace: 'SystemdCgroup = true'

    - name: Restart và enable containerd
      ansible.builtin.service:
        name: containerd
        state: restarted
        enabled: yes

    - name: Cài package phụ trợ
      ansible.builtin.apt:
        name:
          - ca-certificates
          - curl
          - gpg
        state: present
        update_cache: yes

    - name: Tạo thư mục keyrings
      ansible.builtin.file:
        path: /etc/apt/keyrings
        state: directory
        mode: '0755'

    - name: Thêm GPG key Kubernetes
      ansible.builtin.shell:
        cmd: |
          curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.30/deb/Release.key |
          gpg --dearmor --yes -o /etc/apt/keyrings/kubernetes-apt-keyring.gpg
        creates: /etc/apt/keyrings/kubernetes-apt-keyring.gpg

    - name: Thêm Kubernetes repository
      ansible.builtin.copy:
        dest: /etc/apt/sources.list.d/kubernetes.list
        mode: '0644'
        content: |
          deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.30/deb/ /

    - name: Cài kubelet, kubeadm, kubectl
      ansible.builtin.apt:
        name:
          - kubelet
          - kubeadm
          - kubectl
        state: present
        update_cache: yes

    - name: Giữ nguyên version
      ansible.builtin.dpkg_selections:
        name: "{{ item }}"
        selection: hold
      loop:
        - kubelet
        - kubeadm
        - kubectl
```

> Playbook trên sử dụng module `community.general.modprobe`. Nếu máy
> chưa có collection này, cài bằng:
>
> ``` bash
> ansible-galaxy collection install community.general
> ```
>
> Hoặc có thể thay hai task `modprobe` bằng
> `ansible.builtin.command: modprobe ...`.

Chạy:

```bash
ansible-playbook -i inventory.ini prepare-nodes.yml
```

Kiểm tra:

```bash
ansible all -a "hostname"
ansible all -a "free -h"
ansible all -a "df -h"
ansible all -a "systemctl is-active containerd"
```

## 9. Lưu Join Command

Ở cuối output của `kubeadm init` sẽ có lệnh dạng:

```bash
kubeadm join 192.168.70.148:6443 \
  --token <token> \
  --discovery-token-ca-cert-hash sha256:<hash>
```

Nếu quên hoặc token đã hết hạn, tạo lại trên controlplane:

```bash
sudo kubeadm token create --print-join-command
```

> Bootstrap token mặc định có thời hạn. Tạo token mới bất cứ lúc nào khi
> cần là hoàn toàn được.

## 13. THỰC HÀNH 2 --- REJOIN NODE

### 13.0 Kịch bản

Giả sử `workernode2` bị lỗi và cần thực hiện:

``` text
Drain → Delete Node → Reset kubeadm → Cleanup CNI → Join lại
```

### 13.1. Drain node

Trên controlplane:

``` bash
kubectl drain workernode2 \
  --ignore-daemonsets \
  --delete-emptydir-data \
  --force
```

`drain` sẽ evict các workload Pod phù hợp khỏi node.

Các Pod thuộc DaemonSet như:

```text
calico-node
kube-proxy
```

được bỏ qua bởi:

```bash
--ignore-daemonsets
```

Các workload được quản lý bởi **Deployment/ReplicaSet/StatefulSet** sẽ được
controller xử lý và scheduler có thể đặt Pod mới lên node khác nếu điều
kiện cho phép.

Kiểm tra:

``` bash
kubectl get nodes
```

Node có thể chuyển sang trạng thái:

``` text
SchedulingDisabled
```

### 13.2. Xóa node khỏi cluster

Trên controlplane:

``` bash
kubectl delete node workernode2
```

### 13.3. Reset kubeadm trên workernode2

Trên `workernode2`:

```bash
sudo kubeadm reset -f
```

Cleanup cấu hình CNI:

```bash
sudo rm -rf /etc/cni/net.d
```

Nếu node có cấu hình kubeconfig cá nhân:

```bash
rm -rf $HOME/.kube
```

> `kubeadm reset` hoàn tác phần lớn cấu hình do kubeadm tạo trên node.
> Việc xóa `/etc/cni/net.d` giúp loại bỏ cấu hình CNI cũ trước khi join
> lại.

### 13.4. Restart containerd

``` bash
sudo systemctl restart containerd
sudo systemctl enable containerd
```

Không bắt buộc phải restart kubelet trước khi `kubeadm join`. Khi join
lại, kubeadm sẽ thiết lập lại cấu hình cần thiết cho kubelet.

### 13.5. Không flush toàn bộ iptables một cách tùy tiện

Không nên mặc định chạy:

``` bash
iptables -F
iptables -t nat -F
iptables -t mangle -F
iptables -X
```

vì các lệnh này có thể xóa toàn bộ firewall/NAT rules của máy, bao gồm
cả các rule không liên quan đến Kubernetes.

Chỉ thực hiện cleanup iptables khi bạn hiểu rõ các rule đang tồn tại và
lab thực sự yêu cầu.

### 13.6. Tạo Join Command mới

Trên controlplane:

``` bash
sudo kubeadm token create --print-join-command
```

### 13.7. Join lại workernode2

Trên `workernode2`:

```bash
sudo kubeadm join 192.168.70.148:6443 \
  --token <token_moi> \
  --discovery-token-ca-cert-hash sha256:<hash>
```

Kiểm tra kubelet:

```bash
sudo systemctl status kubelet
```

Nếu lỗi:

``` bash
sudo journalctl -u kubelet -xe
```
