# INSTALL HABOR & Lest's Encrypt

## 1. Harbor là gì?

**Harbor** là một private container registry dùng để lưu trữ và quản lý Docker/OCI images.

Hiểu đơn giản:

**Docker Hub** là registry public; **Harbor** là registry private mà doanh nghiệp có thể tự triển khai và quản lý.

Ví dụ:

```text
Developer
    │
    │ docker build
    ▼
Docker Image
    │
    │ docker push
    ▼
┌─────────────────┐
│      Harbor     │
│                 │
│ redmine:1.0     │
│ nginx:1.27      │
│ backend:v2      │
└────────┬────────┘
         │
         │ docker pull
         ▼
    Kubernetes
```

Harbor thường cung cấp:

- Private Docker/OCI Registry
- Quản lý Repository
- Quản lý Image/Tag
- User/Project/RBAC
- Image vulnerability scanning
- Web UI
- Replication giữa các registry
- Audit/logging
- HTTPS/TLS

## 2. Let's Encrypt là gì?

**Let's Encrypt** là một Certificate Authority (CA) cung cấp chứng chỉ TLS/SSL miễn phí.

Mục đích chính:

- Cấp certificate để website/service sử dụng HTTPS.

Ví dụ bạn có: <https://harbor.example.com>

## 3. Let's Encrypt hoạt động thế nào?

Ví dụ bạn có domain: <harbor.example.com>

- Bạn yêu cầu certificate:

```text
Let's Encrypt
      │
      │ xác minh domain
      ▼
harbor.example.com
      │
      ▼
TLS Certificate
```

=> Sau đó cấu hình certificate cho Harbor/nginx/Ingress.

- Client truy cập:

```text
Browser
   │
   │ HTTPS :443
   ▼
harbor.example.com
   │
   ▼
TLS Certificate
   │
   ▼
Harbor
```

=> Browser kiểm tra certificate và tạo kết nối TLS.

## II. CÀI HARBOR VÀ CẤU HÌNH XÁC THỰC TLS TRÊN K8S BẰNG LET'S ENCRYPT

Cụm K8s này sẽ lấy từ các bài lab trước nhưng xoá các resource không liên quan

### 1. Check cluster

Check node: `kubectl get node`

Check namespace: `kubectl get ns`

Check pod các resource hạ tầng cụm: `kubectl get pod -o wide -n <Name_namespaces>`

Check Storage Class: `kubectl get storageclass`

Check Ingress Controller:

`kubectl get ingressclass`  
`kubectl get pod -A | grep -i ingress`

### 2. Chuẩn bị DomainName cho Habor và DNS

Ta sẽ đặt DomainName cho Service là `habor.example.com` , cách tạo ta có thể xem hướng dẫn tại lab cấu hình DNS

### 3. Cài cert-manager

**cert-manager** chịu trách nhiệm tự động xin và gia hạn chứng chỉ TLS từ Let's Encrypt. Dùng Helm:

- Add repo:

```bash
helm repo add jetstack https://charts.jetstack.io
helm repo update
```

- Cài **CRDs** (Custom Resource Definitions):

```bash
kubectl apply -f https://github.com/cert-manager/cert-manager/releases/download/v1.16.2/cert-manager.crds.yaml
```

- Cài cert-manager qua Helm:

```bash
helm install cert-manager jetstack/cert-manager \
  --namespace cert-manager \
  --create-namespace \
  --version v1.16.2
```

- Kiểm tra:

```bash
kubectl get pods -n cert-manager
```

## 4. Tạo Let's Encrypt ClusterIssuer

Tạo **ClusterIssuer** cho Let's Encrypt.

Ví dụ:

```yaml
apiVersion: cert-manager.io/v1
kind: ClusterIssuer
metadata:
  name: letsencrypt-prod
spec:
  acme:
    email: your-email@example.com
    server: https://acme-v02.api.letsencrypt.org/directory
    privateKeySecretRef:
      name: letsencrypt-prod
    solvers:
    - http01:
        ingress:
          ingressClassName: nginx
```

Apply:

```bash
kubectl apply -f clusterissuer.yaml
```

Kiểm tra:

```bash
kubectl get clusterissuer
```

Chi tiết:

```bash
kubectl describe clusterissuer letsencrypt-prod
```

Trạng thái mong muốn:

```bash
Ready: True
```

## 5. Cài Habor bằng Helm

Thêm repository Harbor:

```bash
helm repo add harbor https://helm.goharbor.io
helm repo update
```

Kiểm tra chart:

```bash
helm search repo harbor
```

Tạo namespace:

```bash
kubectl create namespace harbor
```

## 6. Cấu hình Harbor

Tạo file:

```bash
vim harbor-values.yaml
```

Ví dụ cấu hình:

```yaml
expose:
  type: ingress

  ingress:
    className: nginx

    hosts:
      core: harbor.example.com

    annotations:
      cert-manager.io/cluster-issuer: letsencrypt-prod

    tls:
      enabled: true
      certSource: secret
      secret:
        secretName: harbor-tls

externalURL: https://harbor.example.com

harborAdminPassword: "ChangeMe123!"

persistence:
  enabled: true
```

Sau đó cài Harbor:

```bash
helm install harbor harbor/harbor \
  -n harbor \
  -f harbor-values.yaml
```

## 9. Kiểm tra TLS từ client

Truy cập: <https://harbor.example.com>

Hoặc:

`curl -Iv https://harbor.example.com`

Kiểm tra chứng chỉ:

```bash
openssl s_client \
  -connect harbor.example.com:443 \
  -servername harbor.example.com
```

Kiểm tra thời hạn certificate:

```bash
echo | openssl s_client \
  -connect harbor.example.com:443 \
  -servername harbor.example.com 2>/dev/null \
  | openssl x509 -noout -subject -issuer -dates
```

## 10. Kiểm tra Docker Registry

Đăng nhập Harbor: `docker login harbor.example.com`

Build image: `docker build -t harbor.example.com/demo/test:v1 .`

Push image: `docker push harbor.example.com/demo/test:v1`

Kiểm tra image trên Harbor:

```text
Harbor
 └── Projects
      └── demo
           └── test:v1
```

## 11. Test pull image từ Kubernetes

Tạo Secret cho Harbor:

```bash
kubectl create secret docker-registry harbor-registry \
  -n default \
  --docker-server=harbor.example.com \
  --docker-username=admin \
  --docker-password='ChangeMe123!'
```

Kiểm tra:

```bash
kubectl get secret harbor-registry
```

Sau đó sử dụng:

```yaml
spec:
  imagePullSecrets:
    - name: harbor-registry

  containers:
    - name: app
      image: harbor.example.com/demo/test:v1
```

Deploy:

```bash
kubectl apply -f deployment.yaml
```

Kiểm tra:

```bash
kubectl get pod -o wide
```

Nếu Pod pull image thành công thì kiểm tra:

```bash
kubectl describe pod <pod-name>
```
